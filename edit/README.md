# 홈페이지 수정 방법

홈페이지에서 바꿀 수 있는 것은 **모두 이 `edit` 폴더 안에** 있습니다.
수정하고 저장하면 **1~2분 뒤** 홈페이지에 자동으로 반영됩니다.

| 폴더 / 파일 | 무엇을 바꾸나요? |
|---|---|
| `notice` 폴더 | 공지 사진 |
| `schedule` 폴더 | 시간표 사진 |
| `schedule.yml` | 시간표 제목, 선생님 이름, 사진 연결 |

---

## 1. 공지 사진 바꾸기

**`notice` 폴더에 사진을 넣거나 빼기만 하면 끝입니다.**

### 사진 올리기
1. 위 목록에서 `notice` 폴더를 누릅니다.
2. 오른쪽 위 **Add file** → **Upload files** 를 누릅니다.
3. 사진을 끌어다 놓습니다.
4. 맨 아래 초록색 **Commit changes** 버튼을 누릅니다.

### 사진 지우기
1. `notice` 폴더에서 지울 사진을 누릅니다.
2. 오른쪽 위 **…** (점 3개) → **Delete file** 을 누릅니다.
3. 초록색 **Commit changes** 버튼을 누릅니다.

### 알아 두기
- 사진은 **파일 이름 순서대로** 보입니다. 순서를 정하고 싶으면 `01.jpg`, `02.jpg`, `03.jpg` 처럼 이름을 붙이세요.
- 같은 이름으로 올리면 기존 사진이 새 사진으로 바뀝니다.
- 사용 가능한 사진: jpg, jpeg, png, gif, webp

---

## 2. 시간표 사진 바꾸기

### 같은 이름으로 바꾸기 (가장 쉬움)
1. `schedule` 폴더를 누릅니다.
2. **Add file** → **Upload files** 로 **기존과 똑같은 이름**의 사진을 올립니다.
3. 초록색 **Commit changes** 버튼을 누릅니다.

현재 사진 이름:
- 수학: `3-detail.jpg` (크게 보기), `3.jpeg` (목록)
- 영어: `2-detail.jpg` (크게 보기), `2.jpeg` (목록)
- 국어: `1-detail.jpg` (크게 보기), `1.jpeg` (목록)

### 다른 이름으로 올렸다면
`schedule.yml` 에서 `image:` 뒤의 파일 이름을 새 이름으로 고쳐 주세요. (아래 3번 참고)

---

## 3. 시간표 제목·선생님 이름 바꾸기

1. `schedule.yml` 파일을 누릅니다.
2. 오른쪽 위 **연필 모양(✏️)** 버튼을 누릅니다.
3. 글자를 고칩니다.
4. 초록색 **Commit changes** 버튼을 누릅니다.

```yaml
  - title: 수학 시간표       ← 제목
    teacher: 김우진 원장     ← 이름
    image: 3-detail.jpg      ← 크게 보이는 사진 이름
    thumbnail: 3.jpeg        ← 목록 사진 이름 (이 줄은 지워도 됨)
```

### ⚠️ 꼭 지켜 주세요
- 맨 위와 맨 아래의 `---` 줄은 **지우지 마세요.**
- 줄 앞의 **띄어쓰기 칸 수를 바꾸지 마세요.**
- `title:` 처럼 **콜론(:) 뒤에는 한 칸 띄우고** 글자를 적으세요.
- 시간표를 추가하려면 `- title:` 부터 4줄을 통째로 복사해서 붙여 넣으세요.

---

## 홈페이지에 반영이 안 되면?
1. 저장하고 **2~3분** 기다립니다.
2. 홈페이지에서 **Ctrl + F5** (휴대폰은 새로고침)를 누릅니다.
3. 그래도 안 되면 저장소 위쪽 **Actions** 탭에서 빨간 ❌ 표시가 있는지 확인하고, 관리자에게 알려 주세요.
   (대부분 `schedule.yml` 의 띄어쓰기나 `---` 줄 문제입니다.)
